# Android Release Signing (optional)

The default CI build produces a **debug-signed APK** that can be installed
via sideload immediately — no Expo account, no Play Store required.

To produce a **release-signed APK** (required for Play Store or in-place
OTA updates), add the following secrets to your GitHub repository:

| Secret name              | Value |
|--------------------------|-------|
| `ANDROID_KEYSTORE_BASE64` | Base64-encoded `.jks` keystore file |
| `ANDROID_KEY_ALIAS`       | Key alias inside the keystore |
| `ANDROID_KEY_PASSWORD`    | Key password |
| `ANDROID_STORE_PASSWORD`  | Keystore store password |

Then add a `signingConfigs` block to
`artifacts/engram-mobile/android/app/build.gradle` (generated by `expo prebuild`):

```groovy
signingConfigs {
    release {
        keyAlias System.getenv("ANDROID_KEY_ALIAS")
        keyPassword System.getenv("ANDROID_KEY_PASSWORD")
        storeFile file(System.getenv("ANDROID_KEYSTORE_PATH") ?: "debug.keystore")
        storePassword System.getenv("ANDROID_STORE_PASSWORD")
    }
}
buildTypes {
    release {
        signingConfig signingConfigs.release
    }
}
```

Generate a keystore with:
```bash
keytool -genkey -v -keystore engram-release.jks \
  -alias engram -keyalg RSA -keysize 2048 -validity 10000
base64 -i engram-release.jks | pbcopy   # macOS — paste into GitHub secret
```
